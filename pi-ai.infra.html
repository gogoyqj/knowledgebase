Purpose

A unified LLM API library that abstracts 30+ AI providers behind a single streaming interface. Features include automatic model discovery, provider configuration, token/cost tracking, OAuth authentication, and cross-provider conversation handoff.

play_circle Entry & Streaming

index.ts — Main Entry

  • Re-exports everything from the package
  • Imports register-builtins to auto-register all providers
  • Exposes stream(), complete(), streamSimple(), completeSimple()

stream.ts — Core Functions

  • stream() — full async iterable of AssistantMessageEvent
  • complete() — returns final AssistantMessage
  • streamSimple() — text-only async iterable
  • completeSimple() — returns final text string

api-registry.ts — Global API Provider Registry

const registerApiProvider(name: Api, streamFn: StreamFunction) => void
const getApiProvider(name: Api) => StreamFunction
const unregisterApiProviders() => void

Maps API protocol names (e.g. "anthropic-messages", "openai-completions") to their streaming implementation. The stream() function resolves the provider from model.api.

Event Stream Architecture

type AssistantMessageEvent =
  | { type: "start", message: AssistantMessage }
  | { type: "text_delta", delta: string }
  | { type: "thinking_delta", delta: string }
  | { type: "toolcall_delta", id: string, delta: string }
  | { type: "done", message: AssistantMessage }
  | { type: "error", error: Error }

AssistantMessageEventStream is a generic async iterable with push-based event emission, enabling backpressure-free streaming with a .result() promise for the final message.

build Utilities

event-stream.ts

EventStream<T, R> — generic async iterable with push/end/result. AssistantMessageEventStream specialization is the core streaming primitive used by all providers.

overflow.ts

Context overflow detection across all providers. Uses regex patterns for error messages and silent overflow via usage exceeding context window. Returns structured isContextOverflow() result.

validation.ts

Tool argument validation using TypeBox Compile(). Handles JSON Schema coercion, union types, caching validators for performance.

diagnostics.ts

Structured error diagnostics attached to AssistantMessage for post-mortem debugging. Captures provider-specific metadata on failures.

json-parse.ts

JSON repair (control character escaping, invalid escape fixing) and streaming partial JSON parsing via partial-json.

stream-failure.ts

Stream failure classification: refusal, safety, overloaded, rate_limit, etc. StreamFailureError class with recordStreamFailure() for structured logging.

architecture Design Patterns
Strategy Pattern Lazy Loading Event Stream Registry Pattern Adapter Pattern Compatibility Layer Code Generation Graceful Degradation
PatternWhereHow
Strategy api-registry.ts Each API protocol is a strategy registered globally. stream() resolves via model.api and delegates.
Lazy Loading register-builtins.ts Provider SDKs loaded via dynamic import() — only the used provider is loaded at runtime.
Event Stream event-stream.ts Async iterable with push-based emission, backpressure-free streaming, .result() promise.
Registry 3 parallel registries API providers, models, OAuth providers — all support register/unregister/reset lifecycle.
Adapter providers/*.ts Each provider adapts native SDK format → unified AssistantMessageEvent protocol.
Compat Layer Model.compat Fine-grained override of auto-detected capabilities (supportsDeveloperRole, thinkingFormat, cacheControlFormat).
Code Gen models.generated.ts Auto-generated from external catalogs via scripts/generate-models.ts.
Graceful Degradation Everywhere Errors never throw — encoded as AssistantMessage with stopReason: "error". Logger never throws. JSON parsing repairs malformed input.
