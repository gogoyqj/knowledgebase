Architecture Layers

🔧 CLI Layer

Entry point and argument parsing. cli.ts bootstraps the process; cli-main.ts handles the main flow. Sub-modules in cli/ manage daemon launch, session resolution, file processing, and command routing.

⚙️ Core Engine

The shared runtime. AgentSession drives the conversation loop. Tools (bash, edit, ipython) execute actions. Extensions provide plugin hooks. Compaction manages context window pressure.

🚀 Run Modes

Six execution modes: Interactive (TUI), Daemon (background supervisor), ACP (agent protocol), RPC (JSON-RPC), Print (headless), and Agents View (session browser).

🎨 Presentation

40+ Ink/React components for the terminal UI. Theme engine with syntax highlighting. The AgentConnection abstraction bridges modes to the UI layer with InProcess and Daemon variants.

A plugin architecture that lets external modules hook into the session lifecycle. Extensions can register tools, slash commands, modify prompts, and render custom UI.

Key Design Patterns

🏗 Service Injection

createAgentSessionServices() produces a service bag. createAgentSessionFromServices() consumes it. This decouples session creation from concrete dependencies, enabling testability.

🔌 Extension Hooks

Lifecycle hooks (onSessionStart, onToolCall, etc.) allow extensions to intercept and modify behavior without touching core code. Extensions are discovered at startup.

📡 Event Bus

Typed pub/sub (createEventBus()) decouples producers and consumers. Session events flow through the bus to UI components, telemetry, and extensions independently.

🔗 Agent Connection

Abstracts the transport between UI and agent. InProcessAgentConnection for direct mode; DaemonAgentConnection for socket-based daemon mode. Both implement the same interface.

📦 Compaction

When context approaches the window limit, the compaction system summarizes older conversation turns and branch summaries to free space while preserving key information.

🔒 Session Lease

File-based locking prevents concurrent access to the same session. canonicalSessionPath() normalizes paths; SessionAlreadyActiveError guards conflicts.
