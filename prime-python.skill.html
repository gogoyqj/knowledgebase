架构总览

Prime Agent 的 Python Skill 系统采用 TypeScript Host + IPython Kernel + Python Runtime 三层架构。所有 Python Skill 共享同一个持久化 IPython Kernel，模型通过生成代码字符串直接在 Kernel 中执行 Skill。

codeTypeScript Host IPython Kernel Python Runtime (rlm) ZMQ IPC

timeline

执行生命周期

从用户输入到 Skill 执行完成，经过以下阶段：

1

Skill 发现 TypeScript

loadSkills() 扫描三个来源的目录，找到 SKILL.md + pyproject.toml + src/<name>/__init__.py，标记为 Python Skill

2

System Prompt 注入 TypeScript

formatSkillsForPrompt() 生成 <available_skills> XML 块，告诉模型哪些 Skill 已在 Kernel 中可用

3

Kernel 环境引导 TypeScript

ensureKernelPython() 首次运行时通过 uv 创建 venv，安装 ipykernel、prime-agent-runtime、所有 Skill 包

4

Kernel 启动 & Skill 预加载 TypeScript Python

IpythonKernelProvisioner.ensure() 启动 IPython 进程，执行 buildRlmBootstrapCode() 将所有 Skill 模块导入 Kernel 全局命名空间

5

模型生成代码 Python

模型根据 system prompt 中的 Skill 列表，生成 ipython tool call，代码中直接使用 Skill 模块名调用

6

代码发送到 Kernel TypeScript

KernelManager.execute(code) 通过 ZMQ 将代码字符串发送到 IPython Kernel

7

Skill 执行 Python

Kernel 中的全局变量（如 websearch）是预加载的 Skill 模块，await websearch(...) 直接调用 run()

8

结果回传 TypeScript

stdout + result 通过 ZMQ 返回 TypeScript，格式化为 tool_result 喂回模型

启动序列

ipython.ts 
// IpythonKernelProvisioner.startKernel()

// 1. 等待前一个 provisioner 释放 (如 /reload)
await readyGate;

// 2. 创建 KernelManager，启动 IPython 进程
const m = new KernelManager({ python, cwd, env, pythonSkills });
await m.start();

// 3. 恢复上一个 session 的 namespace 快照 (通过 dill)
await m.restoreState();

// 4. 执行 bootstrap 代码 — 导入 rlm + 所有 skills
const bootstrap = await m.execute(buildRlmBootstrapCode(pythonSkills));

Bootstrap 代码注入

buildRlmBootstrapCode() 生成的 Python 代码在 Kernel 启动时执行：

Python (generated) 
import rlm as _prime_agent_rlm_module
rlm = _prime_agent_rlm_module.rlm       # 暴露 rlm 全局对象

import importlib, inspect, sys, types

class _PrimeAgentCallableSkillModule(types.ModuleType):
    async def __call__(self, *args, **kwargs):
        result = self.run(*args, **kwargs)
        if inspect.isawaitable(result):
            return await result
        return result

# 导入所有 Python Skills，包装为可调用模块
for _name in ["websearch", "compact", "goal", ...]:
    try:
        globals()[_name] = _prime_agent_wrap_skill_module(
            importlib.import_module(_name)
        )
    except Exception:
        globals()[_name] = _PrimeAgentUnavailableSkill(_name, ...)
info 导入失败时注入 _PrimeAgentUnavailableSkill 占位对象，Skill 不可用但不会 crash Kernel。

def cli():
    prog = Path(sys.argv[0]).stem         # "websearch"
    module = __import__(prog)              # import websearch
    run = getattr(module, "run")           # websearch.run
    asyncio.run(run_cli(run, prog=prog))  # tyro 解析参数 → 执行

Kernel ↔ Host 通信

prime-agent-runtime/src/rlm/__init__.py

Kernel 中的 Python 代码可以通过 host_request() 反向调用 TypeScript Host：

Python 
# Kernel 中调用 Host 的通用通道
async def host_request(request_type: str, payload: dict | None = None):
    comm = Comm(target_name="host.request", primary=False)
    comm.open(data={**(payload or {}), "type": request_type})
    return await future  # 等待 Host 回复

# 具体的高层 API
await rlm.run("子任务 prompt")          # spawn 子 agent
await rlm.find_models("gpt")           # 搜索可用模型
await rlm.list_subagents()             # 列出子 agent
